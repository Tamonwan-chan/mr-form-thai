# Medication Reconciliation – Data Entry

ฟอร์มกรอกข้อมูล Medication Reconciliation แล้วสรุปเป็นข้อความสำเร็จรูป สำหรับคัดลอกไปวางในเวชระเบียน (HosXP)

**เปิดใช้งาน:** https://tamonwan-chan.github.io/mr-form-thai/MR_form.html

## วิธีใช้
1. กรอกวันที่บันทึก ประวัติแพ้ยา และแหล่งที่มาของยา
2. เพิ่มรายการยา เลือกชื่อยาจากรายการหรือพิมพ์เอง
3. พิมพ์วิธีใช้เป็นรหัสย่อ ระบบจะแปลงให้อัตโนมัติ (ดูตารางด้านล่าง)
4. กด **คัดลอกข้อความ** แล้วนำไปวางในเวชระเบียน
5. หรือกด **พิมพ์สติกเกอร์** เพื่อพิมพ์ลงสติกเกอร์ขนาด 80×60 มม. ถ้าข้อความยาวเกินจะต่อแผ่นถัดไปพร้อมเลขหน้า เช่น 1/2

กดปุ่ม **วิธีใช้** มุมขวาบนของฟอร์ม เพื่อดูสรุปนี้ในโปรแกรม

### รหัสวิธีใช้
| พิมพ์ | ได้ | ความหมาย |
|---|---|---|
| `1*2pc` | `1x2 pc` | ขนาดยา*จำนวนครั้งต่อวัน + pc |
| `1*4ac` | `1x4 ac` | ขนาดยา*จำนวนครั้งต่อวัน + ac |
| `1*hs` | `1x1 hs` | ก่อนนอน |
| `10-2-1-8` | `10-2-1-8 unit sc ac` | อินซูลิน 2-4 มื้อ |

พิมพ์รูปแบบอื่นได้อิสระ ระบบจะไม่แปลงและใช้ข้อความตามที่พิมพ์

### ปุ่มลัด
- **Enter ในช่องชื่อยา** เลือกยาตัวแรกที่ตรงกัน แล้วไปช่องวิธีใช้ (ถ้ายาไม่มีความแรง จะไปช่องความแรงแทน)
- **Tab ในช่องชื่อยา** ข้ามช่องความแรงไปช่องวิธีใช้ ถ้ามีความแรงแล้ว
- **Enter ในช่องวิธีใช้ (แถวสุดท้าย)** เพิ่มรายการยาแถวใหม่

## หมายเหตุ
